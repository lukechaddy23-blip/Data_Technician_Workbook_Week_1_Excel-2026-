# Data Technician Workbook Week 1 Excel 2026

## Overview

This repository contains Excel projects and assignments completed during Week 1 of the Data Technician Bootcamp.

The work focuses on developing core Excel skills used in data analysis, including data cleaning, formulas, PivotTables, filtering, sorting, and data visualisation. The exercises were completed using a variety of datasets including retail sales and bike sales data.

---

## Learning Objectives

During this project, I developed practical experience in:

- Data Analysis using Excel
- Data Cleaning and Preparation
- Filtering and Sorting Data
- Pivot Tables
- Pivot Charts
- Data Visualisation
- Business Insight Generation
- Formula Creation and Troubleshooting
